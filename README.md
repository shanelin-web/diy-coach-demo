# DIY Coach Demo — 泣嘎週烘焙訪

版本：1.4。手機優先的餐飲新人情境訓練展示，包含 7 天、14 個預設情境，以及選用的 Gemini AI 客人功能。

## 試玩

開啟 GitHub Pages 網址，選擇 A、B、C 員工或店長。此為模擬登入，測試密碼為 `1234`，不適用於真實員工權限管理。

固定情境不需要 API。AI 功能需要使用者在設定輸入自己的 Gemini API Key，再測試連線。請勿將金鑰寫進檔案或提交到儲存庫。金鑰僅保存在目前頁面的記憶體，重新整理後需重新輸入。API 可用性與費用依 Google 帳號、模型及額度而定。

## 展示限制

- 訓練資料與品牌均為模擬內容，尚未經企業核定。
- 練習、登入及店長紀錄保存在各自瀏覽器，不會跨裝置同步。
- 預設帳號與密碼不構成正式登入保護，請勿輸入真實員工或公司機密資料。
- GitHub Pages 僅託管前端；若要共用企業 AI 額度，應另設後端管理金鑰與用量。
- 未使用真實金鑰驗證 Gemini 生成與語音，不應將模擬測試當作連線成功。

## 發布

首頁為根目錄的 `index.html`。在 Settings → Pages 設定從 main 分支的根目錄發布。
